# S.O.V. — Serviço de Oftalmologia Veterinária

Sistema de prontuário digital desenvolvido para facilitar o registro, organização e acompanhamento de consultas oftalmológicas veterinárias.

## 🎯 Objetivo

O S.O.V. busca substituir a utilização de fichas físicas por uma solução digital simples e prática, permitindo registrar informações do paciente, exames oftalmológicos, diagnóstico, tratamento e histórico de consultas.

## 🚧 Status

**MVP em desenvolvimento e validação.**

O projeto está sendo desenvolvido com participação de um médico-veterinário oftalmologista, que utiliza o sistema como usuário inicial para validar o produto e sugerir melhorias.

## ✨ Funcionalidades atuais

- Cadastro de pacientes
- Cadastro de proprietário/tutor
- Prontuário do paciente
- Registro de consultas
- Histórico de consultas
- Exame oftalmológico
- Separação entre olho direito (OD) e olho esquerdo (OE)
- Diagnóstico
- Tratamento
- Retorno

## 🔮 Próximos passos

- Anexos e fotos dos exames
- Comparação entre consultas
- Comparação visual de imagens
- Melhorias baseadas no uso real do sistema

## 🛠️ Tecnologias

- React
- TypeScript
- Vite
- Tailwind CSS
- LocalStorage
- Bolt.new

## 🤖 Desenvolvimento

O projeto utiliza **vibe coding** e ferramentas de IA como apoio ao desenvolvimento e prototipação.

A construção do produto é orientada por validação com usuário real, utilizando feedback de um médico-veterinário oftalmologista para definir as próximas funcionalidades e melhorias.

## 📌 Observação

O projeto está em fase de desenvolvimento e validação.

Os dados utilizados no projeto são fictícios. O sistema ainda não deve ser utilizado para armazenamento de dados reais de pacientes.
